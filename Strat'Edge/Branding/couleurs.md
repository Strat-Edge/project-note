## Couleurs Principales (à utiliser en priorité)

| Rôle | Code Hex | Aperçu |
|------|----------|--------|
| **Couleur principale** | `#2F80ED` | Bleu vif — liens, boutons, accents |
| **Couleur secondaire** | `#56A3FF` | Bleu clair — survols, accents secondaires |
| **Fond clair** | `#F4F7FB` | Blanc bleuté — fond de contenu |
| **Fond alternatif** | `#E9EEF5` | Gris bleu clair — sections alternées |
| **Bordure** | `#D5DCE5` | Gris bleu — séparateurs |
